# SolacePoint-API

The official backend API for SolacePoint Insurance Agency. 

This service is responsible for securely collating client leads, submitting quotes, managing consultations, and sending email notifications via the Resend API and storing them in Supabase PostgreSQL.

## Core Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: PostgreSQL (Supabase)
- **Email Service**: Resend
- **Hosting**: Railway / Render
